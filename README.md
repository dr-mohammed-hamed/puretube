# 🛡️ PureTube (نقِيّ)
> **تطبيق يوتيوب الآمن والواقي للشباب والأطفال — بيئة مشاهدة نقية خالية من الفتن ومصائد الإدمان.**

---

## 📖 نظرة عامة
**PureTube** هو عميل يوتيوب خفيف وعصري مبني بأحدث تقنيات أندرويد (`Kotlin`, `Jetpack Compose`, `AndroidX Media3`, `Room DB`) ومستعين بمكتبة `NewPipeExtractor` لجلب البيانات محلياً وبشكل مستقل دون أي خوادم وسيطة.

التطبيق مصمم هندسياً ونفسياً لمحاربة الإدمان والتعافي من الفتن، ومُجهّز للربط المستقبلي مع نواة الذكاء الاصطناعي [`halalify-ai-core`](file:///D:/a/ai_models_for_protection/halalify-ai-core) لتمويه العورات وعزل الموسيقى.

## 🚀 المعالم الأساسية للتطبيق
- **خلاصة الاشتراكات فقط:** لا خوارزميات توصية عشوائية، لا قسم للتريند.
- **مشغل فيديو احترافي:** جودة متعددة، سرعات تشغيل، تشغيل بالخلفية، وضع صورة داخل صورة (PiP).
- **منع الدوبامين السريع:** الفيديوهات القصيرة (Shorts) تُعرض كفيديوهات عادية دون واجهة التمرير اللانهائي.
- **دروع حماية مبدئية:** فلتر الكلمات المحظورة لمنع المحتوى غير اللائق.
- **منافذ للذكاء الاصطناعي (AI Hooks):** واجهات جاهزة في المشغل لاستقبال تمويه الفريمات وعزل الصوت فوراً.
